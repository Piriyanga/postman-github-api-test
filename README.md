# GitHub API Automation with Postman

This project contains GitHub REST API automation tests created using Postman.

## Collection

The collection includes tests for:

- Authenticated user
- User repositories
- Repository details
- GitHub issues
- Updating issues
- Closing issues

## How to use

1. Import the collection into Postman.
2. Import the environment file.
3. Create a GitHub Personal Access Token.
4. Add the token to the Postman environment.
5. Select the environment in Postman.
6. Run the requests in the correct order.

## Important

Never commit a real GitHub token to this repository.
